# Glyph language translation table

This is a simple worksheet for translating Glyph into any language. Leave the English text in the left column unchanged and fill in the target-language translation on the right.

## Translation details

- Target language: `[language]`
- Translator: `[name or handle]`
- Date: `[YYYY-MM-DD]`

## Notes for translators

- Translate the text as it should naturally appear in the app.
- Keep placeholders such as `{{count}}`, `{{date}}`, `{{tag}}`, `{{folder}}`, `{{name}}`, `{{label}}`, `{{message}}`, `{{section}}`, `{{title}}`, `{{tab}}`, and `{{tool}}` exactly as written. You may move them within a sentence if your language needs a different word order.
- Keep `<discord>` and `</discord>` unchanged, but translate the words between them.
- Translate singular and plural wording separately when the English rows differ.
- The settings-search section also includes search words. Translate those so people can find settings in the target language.
- Keep names such as Glyph, Git, AI, Markdown, and programming-language names according to normal usage in the target language.
